# Catatan sumber aset

Folder `assets/` berisi logo GrowMate, avatar persona, gambar postingan contoh, poster Opportunity, dokumen materi, dan logo pencarian beasiswa. Sebagian merupakan materi yang sudah ada di ZIP proyek sebelumnya, dan beberapa gambar ditambahkan berdasarkan lampiran pemilik proyek pada sesi revisi.

**Status lisensi:** belum dilakukan audit izin publikasi menyeluruh untuk seluruh gambar/poster/foto dan PDF. Penggunaan pada MVP untuk review tidak otomatis memberikan hak untuk menerbitkan ulang, memodifikasi, atau memakai aset untuk tujuan komersial. Sebelum membuat repository GitHub publik atau memublikasikan aplikasi:

1. Pastikan setiap logo, wajah, poster, berita visual, dan PDF boleh digunakan serta cantumkan atribusi yang diperlukan.
2. Ganti aset yang lisensinya tidak jelas dengan aset milik sendiri atau berizin.
3. Jangan mengklaim kesempatan/event contoh telah terverifikasi atau masih terbuka tanpa konfirmasi resmi.
4. Hindari informasi pribadi pihak ketiga tanpa persetujuan.

Gambar contoh bukan bukti kejadian atau bukti pendukung klaim berita. Referensi ilmiah/sumber acara harus dinilai secara terpisah.
