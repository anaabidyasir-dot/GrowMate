# Rencana pengembangan berikutnya

Daftar ini adalah **rencana**, bukan fitur yang sudah dikirim.

## Prioritas 1 — fondasi produksi

- Autentikasi server dan verifikasi email, reset password, session/cookie aman.
- Database pengguna, postingan, materi, opportunity, relasi pengikut, serta kebijakan akses.
- API laporan dan moderasi dengan status terukur, admin berizin, anti-spam dan log audit.
- Penyimpanan media aman, pemrosesan dan pemindaian file.
- Pengujian aksesibilitas dan penggunaan perangkat asli.

## Prioritas 2 — pengalaman terhubung

- Chat realtime, undangan diterima/ditolak, notifikasi terverifikasi, dan aktivitas lintas perangkat.
- Perhitungan followers nyata, feed komunitas, dan profil publik berbasis otorisasi.
- Direktori kampus terverifikasi, approval server-side, dan kebijakan data akademik.

## Prioritas 3 — kualitas operasional

- Telemetri dengan persetujuan pengguna, pemantauan error, cadangan data, pemulihan bencana, dan kebijakan retensi.
- CI untuk pengujian otomatis dan pemeriksaan keamanan sebelum merge.
- Audit hak penggunaan aset dan kualitas sumber Opportunity.
