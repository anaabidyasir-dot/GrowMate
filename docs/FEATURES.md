# Status fitur GrowMate

Status di bawah membedakan interaksi yang sudah berfungsi lokal dan layanan yang perlu backend.

| Fitur | Status MVP | Perlu backend agar produksi |
| --- | --- | --- |
| Daftar / masuk dengan username & kata sandi | Berfungsi di browser | Autentikasi terverifikasi, pemulihan akun, sesi aman |
| Unggah postingan, komentar, suka, simpan | Tersimpan lokal | Feed publik dan hak akses antar pengguna |
| Bagikan tautan postingan/materi/Opportunity | URL dapat dibuat | Pengambilan konten dari server bagi penerima |
| Laporkan postingan/materi/Opportunity/akun | Form dan riwayat lokal | Antrean moderasi, pencegahan spam, audit |
| Sembunyikan setelah melapor | Konfirmasi Ya/Tidak | Sinkronisasi preferensi akun lintas perangkat |
| Blokir akun | Penyaringan lokal | Enforcement server dan kebijakan sosial |
| Profil publik dan pengikut | Tab konten + angka pengikut contoh | Social graph dan angka pengikut nyata |
| Katalog Learning dan progres bab | Berfungsi lokal | Penyimpanan progres dan materi lintas perangkat |
| Katalog Opportunity dengan poster | Kartu dan detail tersedia | Verifikasi sumber, kurasi, pelaporan massal |
| Ask Space dan Ajukan chat | Form/chat lokal | Routing permintaan ke petugas dan pesan sungguhan |
| Admin kampus | Simulasi dalam browser satu origin | Validasi institusi, otorisasi, audit, API akademik |
| Pengaturan & riwayat aktivitas | Berfungsi lokal | Sinkronisasi dan retensi data transparan |

## Konten awal

Beranda, Learning, dan Opportunity menampilkan konten contoh untuk membantu review. Dua entri Opportunity tanpa gambar dari revisi sebelumnya telah dihapus. Konten yang ditambahkan pengguna tetap berada di penyimpanan akun lokal; tidak dipublikasikan ke perangkat lain.
